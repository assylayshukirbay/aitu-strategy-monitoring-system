# AITU Strategy Monitoring System — Architecture Diagrams

This directory contains the required architecture and system-design diagrams.

| Diagram | Editable source | Image export |
| --- | --- | --- |
| System Context Diagram | `system_context.mmd` | `system_context.png` |
| Use Case Diagram | `use_case.puml` | `use_case.png` |
| Component Diagram | `component_diagram.mmd` | `component_diagram.png` |

## Editing the diagrams

- **Mermaid (`.mmd`)**: Open the source in [Mermaid Live Editor](https://mermaid.live), make changes, and export the updated PNG.
- **PlantUML (`.puml`)**: Open the source in a PlantUML-compatible editor, make changes, and export the updated PNG.
- When modifying the architecture, update **both** the source and its PNG export, and keep the report consistent.

## Diagram descriptions

1. **System Context Diagram:** Identifies the system boundary and external user groups.
2. **Use Case Diagram:** Illustrates interactions between user roles and the main system functions.
3. **Component Diagram:** Describes the main application components and their relationships with the database.

The `Change History` functionality is shown in the design, but its advanced implementation is outside the minimum required MVP scope.
