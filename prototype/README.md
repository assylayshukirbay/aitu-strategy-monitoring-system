# AITU Strategy Monitoring System — UI Prototype

This folder contains an interactive HTML prototype prepared for the first pre-defense of the individual diploma project.

## How to open

Open `AITU_Strategy_Prototype.html` in a desktop web browser. No installation or server is required.

## Screens

- Dashboard
- KPI Management
- KPI Details
- Reports

Screenshots of the four screens are stored in `screenshots/`.

## Scope

The prototype illustrates the proposed user interface and workflow using demonstration data. It is not a deployed application. It does not implement backend authentication, database persistence, or university-system integrations. The planned system architecture and requirements are documented separately in the project report.
