# Verification and Evaluation

This directory contains the planned verification and evaluation materials for the **AITU Strategy Monitoring System**. These plans correspond to Section 9 of the first pre-defense report.

## Files

- `TEST_PLAN.md` — test approach, environments, evaluation procedure, and metrics.
- `test_cases.csv` — 14 planned functional and validation test cases, including acceptance criteria and execution status.
- `baseline_tasks.csv` — three standardized comparison tasks for spreadsheet and application workflows.
- `evaluation_results_template.csv` — blank template for future measurements.

## Status

**Planning only.** Functional system tests, performance measurements, and user evaluations have not yet been carried out. The current HTML interface is a demonstration prototype and is not evidence of backend functionality, database persistence, or access controls.

Test results should be recorded only after the corresponding functionality is implemented and tested. `TC-10` (change history) is conditional because detailed audit history is optional in the initial scope.
