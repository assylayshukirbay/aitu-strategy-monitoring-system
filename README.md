## About the Project

The AITU Strategy Monitoring System is a diploma project aimed at developing a centralized platform for monitoring the implementation of Astana IT University's Development Strategy for 2026–2030.

The system is intended to help university staff manage strategic goals, track key performance indicators (KPIs), compare annual targets with actual results, and prepare monitoring reports.

## Main Features

The planned system will support management of strategic goals and KPIs, tracking of annual targets and actual results, KPI validation and calculation, dashboards, reporting, user authentication, and role-based access control.

## Intended Users

The system is designed for strategy monitoring staff, department representatives, university management, and system administrators.

## Technologies

The proposed technology stack includes Python, Django, PostgreSQL, HTML, CSS, JavaScript, and Chart.js.

Technology choices will be finalized during development.

## Interactive Prototype

The current HTML prototype includes four screens: Dashboard, KPI Management, KPI Details, and Reports.

To open the prototype, download `prototype/AITU_Strategy_Prototype.html` and open it in a web browser.

The prototype uses demonstration data. It does not currently include backend services, persistent storage, or real user authentication.
