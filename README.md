## Project Description

This project focuses on developing an automated system for monitoring and controlling the implementation of the AITU Development Strategy.

The proposed system will organize strategic goals, KPIs, annual targets, and actual results to support consistent monitoring and reporting.

## Problem Statement

Strategy monitoring currently involves information distributed across documents and spreadsheets. The proposed system aims to provide a centralized structure for KPI information, comparison of planned and actual results, and preparation of monitoring reports.

## Target Users

- Strategy monitoring staff
- Department representatives
- University management
- System administrators

User roles and permissions are preliminary and subject to stakeholder validation.

## Project Scope

**Core functionality:**
- Management of strategic goals and KPIs
- Annual target and actual result tracking
- KPI comparison and validation
- User authentication and role-based access
- Dashboards and reporting

**Out of scope:**
- AI forecasting
- Unauthorized integration with internal university systems
- Complex approval workflows

## Expected Outcomes

A functional system prototype, technical documentation, architectural diagrams, and testing results.
